Lyrhythmics is a lyrics typing game.  
It's made using Vue.js and TailwindCSS.  
You can play it on [my website](https://lyrhythmics.k327.eu), [Newgrounds](https://www.newgrounds.com/portal/view/981530) or [itch.io](https://k327-games.itch.io/lyrhythmics).
It contains a lot, so I won't go into detail here. Just play the game, check out the editor, and look at the settings to see what most of it is like.  
There's also an about page in-game explaining some non-basic aspects of it. If you'd prefer to read it here and not in game, go to /src/views/Home.vue, line 908.  
Regarding modifying and not playing the game, if you'd want to have it with a custom list of songs in the menu, /public/maps/ contains the maps themselves, /src/songSamples/ contains the 7.5 second samples that are played in the main menu, and /src/configs/mapList.json is the list of maps with metadata. The sizes there are in kilobytes. If you just want to use the official song list but without songs that disallow commercial use, set "commercial" to true in /src/configs/config.json  
The other settings in config.json are platform, enableFullscreenButton and defaultTheme. Platform is used for special text on the about page on Newgrounds and itch.io, enableFullscreenButton is used for adding a fullscreen button to the main menu, preloadMaps loads all the maps during the loading game screen, and defaultTheme is the default theme, like how you'd configure a theme in-game in the settings. You can do that and export the theme in-game, and then paste it into defaultTheme in the config file.  
vite-plugin-singlefile is used to combine html, js, css and background.jpg into one html file. This was required to publish the game on Newgrounds and itch.io.
